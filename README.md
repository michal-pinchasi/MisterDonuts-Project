# MisterDonuts-Project
# Mr. Donuts - Israeli Food & Marketing Site 🍩

אתר תדמיתי בעיצוב מודרני עבור חברת "מיסטר דונאטס", המתמחה בייצור ושיווק דונאטס .

##  תכונות מרכזיות במערכת
* **עיצוב רספונסיבי מלא:** התאמה מושלמת לכל סוגי המסכים (Mobile First) באמצעות Media Queries מתקדמים.
* **גלריית מוצרים דינמית:** הצגת מארזי דונאטס עם פירוט מחירים ומידע תזונתי .
* **ממשק אינטראקטיבי:** שימוש באנימציות CSS (Keyframes) ליצירת גלריית תמונות נעה אוטומטית.
* **טופס יצירת קשר:** אזור ייעודי להשארת פרטים עבור לקוחות פרטיים ועסקיים.
* **מבנה גריד מורכב:** שימוש ב-CSS Grid להצגת "חדשות המיסטר" בצורה ויזואלית מעניינת.

##  טכנולוגיות וכלים
* **HTML5:** מבנה סמנטי נכון הכולל Header, Main ו-Footer.
* **CSS3 (Advanced):** שימוש ב-Flexbox, Grid, אנימציות ועיצוב רכיבים מותאמים אישית (כמו Scrollbar מעוצב).
* **UI/UX:** דגש על חוויית משתמש צבעונית ומזמינה המותאמת למיתוג החברה.
